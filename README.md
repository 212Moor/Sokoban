# Sokoban

Sokoban est un jeu de réflexion dans lequel le joueur doit déplacer des caisses vers des emplacements prédéfinis afin de terminer chaque niveau.

Le déplacement des caisses nécessite d'anticiper les mouvements : une caisse bloquée contre un mur ou dans un coin peut empêcher la résolution du niveau.

## Fonctionnalités

- Déplacement du joueur sur une grille.
- Poussée des caisses vers les emplacements cibles.
- Détection de la réussite d'un niveau.
- Résolution basée sur la logique et l'anticipation des déplacements.

*La liste des fonctionnalités devra être ajustée en fonction de l'implémentation actuelle du projet.*

## Règles du jeu

1. Déplacer le joueur sur les cases accessibles.
2. Pousser les caisses vers les emplacements cibles.
3. Les caisses ne peuvent pas être tirées.
4. Une caisse ne peut pas être poussée à travers un mur ou une autre caisse.
5. Le niveau est terminé lorsque toutes les caisses requises sont placées sur leurs cibles.
